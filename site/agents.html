← Back to UniView UniView for coding agents

A clearer handoff.

Bring files, structured views, and review requests from your coding agent into a workspace you can inspect.

Show the work

Agents can open local files or render structured view specifications containing tables, metrics, trees, and diffs.

Request a human decision

A review receipt describes the completed work and changed files. UniView verifies file hashes when the person approves or requests changes, then returns a decision record to the agent.

Connect through MCP

The desktop app includes a stdio MCP server. Windows packaged builds provide a launcher at resources\uniview-mcp.cmd. Add that launcher as a local MCP server in your agent client.

Or use the command line

UniView open report.pdf
UniView open --wait --receipt review.receipt.json

Manage access

The Agents panel shows connected sessions, enrolled clients, and activity. Revoke enrolled clients from the same panel. Names reported by agents are not proof of identity; the integration trusts the local OS user account.

Review decisions are made on the desktop. Phone receipt views are read only.
