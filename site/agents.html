A clearer handoff.

Bring files, structured views, and review requests from your coding agent into a workspace you can inspect.

Install, connect, ask

  1. Install UniView on Windows from the download on the home page.
  2. On the Home screen, click Connect beside Claude Code and confirm. UniView adds itself to Claude Code's settings using Claude Code's own command.
  3. Ask Claude Code to show you a document. It opens in a UniView tab. The first time, approve the agent in the prompt UniView shows.
  4. Type the change you want in the bar under the document and send it. The agent edits the file, and the tab reloads with the change.

Codex can be connected the same way, but it is a preview, not yet tested end to end.

What agents can show

Local files in viewer tabs, and structured view specifications with text, tables, metrics, trees, code, diffs, images, and charts.

Request a human decision

A review receipt describes the completed work and the changed files with SHA-256 hashes. When the person clicks Approve or Request changes, UniView verifies the hashes and returns a decision record to the agent.

Manual setup

The Connect button on Home is the short path. Setting the connection up by hand is optional.

Through MCP: the desktop app includes a stdio MCP server. Windows packaged builds provide a launcher at resources\uniview-mcp.cmd. Add that launcher as a local MCP server in your agent client.

UniView open report.pdf
UniView open --wait --receipt review.receipt.json

Manage access

The Agents panel shows connected sessions, enrolled clients, and activity. Revoke enrolled clients from the same panel. An enrolled client authenticates with the key UniView stored when you allowed it; the name in that first prompt is only what the client reports.
